# 个人认知沉淀 · AI 生成与维护提示词手册

本手册提供可直接复制给 AI 执行的标准化提示词。核心原则：**规则写在固定的 `.md` 规范里，每次让 AI 先读规范再动手干活，不靠死板脚本硬套。**

> [!TIP]
> 在本工作区打开 Antigravity 对话时，根目录的 [AGENTS.md](../AGENTS.md) 与工作区技能已配置**自动识别**：你把文章（或文章 + 对话）直接发到窗口即可触发制作；如果你更习惯「文章 + 提示词」明确配对发给 AI（或在其他对话窗口使用），可直接复制或 `@` 引用独立的 [一键沉淀提示词.md](./一键沉淀提示词.md)，或使用下方「提示词 1」。

---

## 提示词 1（最常用·零准备直出）：文章 / 对话 + 提示词直接发给 AI

> 适用场景：**不用提前建文件夹、不用自己起主题名**。直接把下面的提示词和你的文章（或链接 / PDF / 截图 / 原文+AI对话）一起发给 AI，AI 会自己看里面的内容、判定是纯文章还是文章+对话、判定语种、自动起名并归档到 `private/<主题短名>/raw/`，然后做出全套产物。也可直接 `@规范/一键沉淀提示词.md` 后接文章正文。

```text
请把下面（或随附）的文章/材料与对话内容，按当前「个人认知沉淀」工作区根目录的规范自动识别并生成全套认知沉淀产物。

开始前，请先完整阅读：
1. `README.md`
2. `index.md 框架与生成规范.md`
3. `规范/HTML 回顾页规范.md`
4. `规范/PDF 排版规范.md`

请先仔细阅读我发给你的内容，自动完成以下判断与归档（无需我提前建文件夹或起名）：
- 判断材料形态：如果只有纯文章/原文（无历史 AI 对话），参考 `private/预设熵增/index.md` 的写法，在「我想弄懂」「当前停点」「续聊状态」「完整对话」中如实注明「本次材料未涉及历史对话」，「我的思考轨迹」按原文逻辑转折组织，严禁捏造用户对话；如果包含原文 + AI 对话，严格按 `S01/S02...` 和 `C01/C02...` 还原我的思考轨迹与待决策提案。
- 判断原文语种：外文输出 `纯英文原文.pdf`、`纯中文原文.pdf`、`中英原文.pdf` 三件套；纯中文输出 `<主题短名>·原文精排.pdf`。
- 自动提炼 `<主题短名>`（2～8 字）和英文 `<Topic>`，默认在 `private/<主题短名>/` 建立目录与 `raw/`，把本次提交的原文与对话原样存入 `raw/`（若我已提前放好 `raw/` 则直接读取并保持原样）。

请按以下顺序完成全部产物（文件名前缀必须带 `<主题短名>`，禁止只叫 `review`/`source`；主题目录不残留临时文件）：
1. `<主题目录>/index.md`
2. `<主题目录>/<主题短名>·认知精华.html`
3. `<主题目录>/<主题短名>·认知精华.pdf`
4. 原文精排 PDF（外文三件套 / 纯中文单份）
5. `<主题目录>/en/` 纯英文四件套（100% 纯英文、不含中文字符，原图/原文件引用 `../raw/...`）：
   - `en/index.md`
   - `en/<Topic> - Key Takeaways.html`
   - `en/<Topic> - Key Takeaways.pdf`
   - `en/<Topic> - Original Text.pdf`

全部生成后，请实际打开中英文 HTML 验证离线加载、搜索过滤、就地展开原文、375px 手机竖屏无横向溢出及原图加载；并逐页检查所有 PDF 的分页、页眉页脚与版式。最后给我全部产物的路径和实测结果。

---
以下是本次要处理的内容：
<把文章正文 / 链接 / 对话记录贴在这里，或直接附上 PDF/截图>
```

## 提示词 2：已手动建好 `raw/` 目录时的一键沉淀

> 适用场景：你已经自己新建了 `<主题目录>`，并提前把原图/原文和对话放进 `<主题目录>/raw/`，想明确指定目录名与短名。

```text
请处理当前「个人认知沉淀」工作区根目录下的新主题 `<主题目录>`。

开始前，请先完整阅读：
1. `README.md`
2. `index.md 框架与生成规范.md`
3. `规范/HTML 回顾页规范.md`
4. `规范/PDF 排版规范.md`
以及 `<主题目录>/raw/` 里的全部原文、图片和完整对话记录（如有我附带的补充说明也一并纳入）。

请按以下顺序独立完成产物（输出文件名前缀必须带上 `<主题短名>`，禁止只叫 `review`/`source`；同时保持 `raw/` 原样不动，不在主题目录残留临时文件）：
1. `<主题目录>/index.md`：严格遵守固定章节、四种归因标记与证据编号（S01/C01/J01/G01），写透每条判断的理由、边界和例子，完整转录原文并附上完整对话。
2. `<主题目录>/<主题短名>·认知精华.html`：以 `index.md` 为底稿，严格遵守 `规范/HTML 回顾页规范.md`。使用纯白底色 `#FFFFFF` + 唯一陶红强调色，去掉彩色胶囊，做成「从上往下」单栏认知操作台（吸顶搜索与索引条、树状思维导图、30 秒速讲卡、速览/精读切换且可就地展开原文与对话的判断列表、底部折叠原材料库）。
3. `<主题目录>/<主题短名>·认知精华.pdf`：以 `index.md` 为底稿，严格遵守 `规范/PDF 排版规范.md` 导出极简出版风回顾版 PDF。
4. 原文精排 PDF（若原文为外文，必须输出三份；纯中文材料则输出 `<主题短名>·原文精排.pdf`）：
   - `<主题目录>/<主题短名>·纯英文原文.pdf`（只有英文）
   - `<主题目录>/<主题短名>·纯中文原文.pdf`（只有中文，忠实直译）
   - `<主题目录>/<主题短名>·中英原文.pdf`（中英文对照集合版）
5. `<主题目录>/en/` 纯英文产物子文件夹（100% 纯英文，不含任何中文字符；若原对话为中文须完整译成英文，原图/原文件引用使用 `../raw/...`）：
   - `<主题目录>/en/index.md`
   - `<主题目录>/en/<Topic> - Key Takeaways.html`
   - `<主题目录>/en/<Topic> - Key Takeaways.pdf`
   - `<主题目录>/en/<Topic> - Original Text.pdf`

全部生成后，请实际打开 HTML 验证离线加载、搜索过滤、就地展开原文、手机竖屏（375px）无横向溢出及原图加载；并逐页检查所有生成的 PDF 的分页、页眉页脚与版式。最后给我全部产物的路径和实测结果。
```

## 提示词 3：只重生成某一个产物

> 适用场景：修改了 `index.md` 或某份样式规范，只想让 AI 单独更新其中某一个产物。

```text
我更新了 `<主题目录>/index.md`（或更新了 `规范/HTML 回顾页规范.md` / `规范/PDF 排版规范.md`）。

请先重读最新规范与 `<主题目录>/index.md`，仅重新生成 `<目标文件名>`（不要改动 `raw/`，也不要改动其他未指定的文件）。

生成后请做实际渲染与分页验收，并汇报改动点与验证结果。
```

## 提示词 4：把 `index.md` 带进新对话继续聊

```text
这是我之前整理的一份认知沉淀底稿 `index.md`。请你先重点读第 1 节「主题与讨论进度」、第 3 节「续聊状态」，以及相关判断卡。

请先用 3 句话向我复述：
1. 我上次最想弄懂什么、讨论停在哪个具体问题；
2. 我已经明确表达过哪些偏好或决定；
3. 目前有哪些待决策提案等我拍板。

复述确认后，我们直接从「可从这里接着聊」往下推进。
```

## 提示词 5：把新的排版喜好永久写进规范

```text
刚才生成的 `<目标文件名>` 中，我希望把以下要求固定成以后所有主题都遵守的规则：
- <写下你的具体调整>

请只更新对应的规范文件（`规范/HTML 回顾页规范.md` 或 `规范/PDF 排版规范.md`），并顺便用新规则重新生成 `<主题目录>` 的对应产物给我验收。
```
