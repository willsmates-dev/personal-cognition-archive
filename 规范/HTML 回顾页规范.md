# 个人认知沉淀 · HTML 回顾页规范

本文件规定每篇主题目录下 **`<主题短名>·认知精华.html`**（例如 `Naval的杠杆·认知精华.html`，禁止统一命名为无辨识度的 `review.html`）的风格、纵向操作台布局、交互能力与离线约束。AI 生成该 HTML 时，必须先读取主题的 `index.md` 与本规范；所有事实、文字、归因与编号均以 `index.md` 为准。

---

## 1. 视觉风格：纯白底色 + Claude 科技长文克制风（极简、零花哨杂色）

- **色彩极度收敛**：
  - **页面主背景一律纯白 `#FFFFFF`**（不用偏黄发暗的米黄大底），卡片白底 `#FFFFFF` 配细灰边框 `#E4E0D8`，仅在极少数表头、分支节点或交互悬停区使用极浅中性灰 `#F7F7F5` / `#EFECE6`，深炭黑正文 `#141413`，辅助灰 `#6B6964`。
  - **全站唯一强调色**：陶红棕（`#B44E2D` / `#8B3A1E`），仅用于顶部细线、分节编号、重要左竖线、选中态边框与关键按钮。
  - **禁止使用多种彩色药丸**：不得用紫、蓝、黄、绿等彩色徽章铺满页面。归因身份（`作者`、`我`、`AI`、`待决策`）只用极简的等宽小字标签或细灰/陶红细线标注，保持长文阅读的沉稳与干净。

---

## 2. 布局方向：严格「从上往下」单栏操作台

页面采用桌面居中单栏（最大宽 `840px–880px`）、手机自然全宽的**从上往下纵向阅读流**（不做左右多栏挤压正文），同时把「检索、思维导图、速讲复述、就地展原文」作为操作能力嵌在纵向流中：

1. **顶部吸顶轻工具条（Sticky Bar）**
   - **关键词过滤框**：输入任意词实时筛选相关判断卡与原文提示（附清空与命中计数）。
   - **快捷锚点索引**：一行直达「主旨 / 思维导图 / 速讲 / 判断 J01–Jn / 续聊 / 原文库」。
   - **视图模式切换**：支持一键切换 `速览模式`（默认，仅露标题与核心结论）与 `精读全展`（展开全部论证）。
2. **开篇区：核心问题、一句话理解与思考路径**
   - 标题、来源与核心问题后，用左侧陶红竖线突出「最值得留下的理解」，紧接一条紧凑的 `1 → N` 思考轨迹（交代怎么一路问下来）。
3. **思维导图区（交互式 SVG 树状脉络）**
   - 展示从中心母题向外分叉的**树状思维导图**（`中心问题 → 核心分支 → 具体判断节点 J01–Jn / 待决策提案`）。
   - 桌面端使用横向展开树，手机端（`<= 700px`）切换为竖向缩进树状 SVG，严禁把大图硬缩成看不清的小字。
   - 点击任意分支或叶节点，平滑滚动定位到下方对应的判断卡并高亮点亮。
4. **「快速讲出观点」30 秒口述卡**
   - 专门面向对外复述或快速回忆的浓缩卡片：**1 句核心结论 + 3 条骨干逻辑 + 1 个最易懂的对比例子**，配「一键复制口述稿」按钮。
5. **核心判断操作列表（`J01–Jn` + 对照表）**
   - **默认处于速览态**：每张卡仅展示 `J0x` 编号、标题与左竖线一句话结论，方便快速扫读。
   - 每张卡下方内置两个**就地展开抽屉**（不跳离当前视角）：
     - **`展开论证`**：查看「为什么成立」「边界或反例」「关键例子」。
     - **`就地对照原文与对话`**：直接在当前判断卡正下方展开相关的原文摘录、对应对话轮次摘要及原图缩略入口，看完随时收起。
6. **续聊停点与待决策区**
   - 清晰列出最后具体问题、已明确偏好、尚未敲定的问题，并用陶红细虚线框标出 `[待决策]` 提案与「可从这里接着聊」的 3 条接续方向（配「复制续聊开场白」按钮）。
7. **底部完整原材料库（默认折叠）**
   - 使用原生 `<details>`/`<summary>` 默认收起：分别提供完整原图（支持原生 `<dialog>` 放大灯箱）与逐页转录、以及完整逐轮对话记录，确保浏览器 `Cmd+F` 可检索且点击外部锚点可自动展开。

---

## 3. 工程与验证硬性约束

- **100% 离线单文件**：CSS、SVG、JS 全部内联，零外部 CDN 请求；所有原图与底稿走相对路径（`./raw/...`、`./index.md`）。
- **双端零溢出与无障碍**：CSS Grid 使用 `minmax(0, 1fr)` 与 `min-width: 0`，确保 `375px` 手机竖屏 `scrollWidth <= innerWidth`；不使用行内 `onclick`；标题不放进 `<summary>`。
- **交付自查**：以 `file://` 打开验证外链为 0、控制台报错为 0、375px 手机竖屏与 1280px 桌面布局完整、思维导图字号清晰、就地对照与底部原图均可正常展开加载。

---

## 4. `en/` 纯英文版 HTML 规范

每个主题目录的 `en/` 子文件夹下必须同步生成纯英文版操作台 **`en/<Topic> - Key Takeaways.html`**（例如 `en/Naval's Leverage - Key Takeaways.html`）：
- **100% 纯英文呈现**：设置 `<html lang="en">`，所有导航按钮、搜索框占位符、归因微标（`Author` / `Me` / `AI` / `Pending`）、思维导图 SVG、30 秒速讲卡、一键复制话术、判断卡与底部原材料（含原对话译文）全部使用自然英文，严禁混入中文字符。
- **相对路径适配**：底稿与 PDF 指向同目录 `./index.md`、`./<Topic> - Key Takeaways.pdf`、`./<Topic> - Original Text.pdf`；原图与原始对话文件指向 `../raw/...`。
