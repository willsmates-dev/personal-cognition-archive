# 个人认知沉淀 · PDF 排版规范

本文件规定每个主题需要生成的 PDF 产物命名规范与出版级版式标准（文件名前缀必须带主题短名，方便单独导出传阅，禁止只叫 `review.pdf` / `source.pdf`）：

1. **`<主题短名>·认知精华.pdf`** —— **认知沉淀回顾版**：基于 `index.md` 提炼，面向快速复盘、通读与续聊交接（如 `Naval的杠杆·认知精华.pdf`）。
2. **原文精排 PDF 套装**（外文材料必须同时输出以下 **3 份**；若原文为纯中文则输出 `<主题短名>·原文精排.pdf`）：
   - **`<主题短名>·纯英文原文.pdf`**（或对应原语种）：只有原文，100% 忠实重排。
   - **`<主题短名>·纯中文原文.pdf`**：只有中文，100% 忠实直译，不掺入 AI 扩展点评。
   - **`<主题短名>·中英原文.pdf`**：中英文对照集合版（每节英文原段下紧跟忠实中文译文），方便对照精读。

全部 PDF 均对标《预设熵增 · JA Westenberg（中文完整版）》与 Claude 科技长文的极简、克制、高对比度出版美学。

---

## 1. 共同版面与视觉规范（极简无杂色）

- **纸张与页边距**：标准 A4 纵向（`210mm × 297mm`），页边距统一 `>= 20mm`（推荐上下 `21mm`、左右 `20mm`），留足呼吸空间。
- **色彩克制铁律**：
  - 纸白底 `#FFFFFF`、深墨黑正文 `#141413`（严禁正文泛灰）、辅助灰 `#78756E`。
  - **唯一强调色**：深红棕/陶红（`#8B3A1E`）。用于首页顶部 `2.5pt` 粗横线、分节编号、重点左竖线、表头/首列适度强调。
  - **禁止彩色小药丸**：不在 PDF 里使用蓝/黄/紫/绿各种小色块标签。`<主题短名>·认知精华.pdf` 中的归因（`作者`、`我`、`AI`、`待决策`）只用细框灰底或纯文字等宽微标区分；三份原文 PDF 则保持纯粹原典排印，不加多余干扰标记。
- **字阶与行距**：
  - 正文字号 `10pt–10.5pt`，行距 `1.48–1.58`，段间距 `7pt–9pt`。
  - 页眉（首页隐藏）使用 `8.5pt` 灰字 + `0.5pt` 细底线；页脚左侧为文档短名，右侧为 `Page X of Y`。
- **防截断规则**：所有标题设 `break-after: avoid`；引文块、表格、思维脉络图与提示框设 `break-inside: avoid`。

---

## 2. `<主题短名>·认知精华.pdf` 内容组织（回顾与复述版）

1. **首页开篇**：`2.5pt` 红棕顶线 + 眉标 + 主标题 + 副标题 + 核心问题与一句话理解（左竖线引文）+ 元数据收束线。
2. **`01` 思考轨迹与思维脉络**：
   - 暖灰表头（`#EFECE6`）紧凑思考轨迹表（步骤 `01–0N`）。
   - **静态高清矢量树状思维导图（SVG）**：从中心命题分出主干枝与判断叶节点，整图不跨页拆裂。
3. **`02` 快速讲出观点（30 秒复述提纲）**：独立方框，浓缩「1 句核心 + 3 个支撑点 + 1 个生活对比例子」，方便印出后直接开口复述。
4. **`03` 讲透的判断与对照表**：按 `J01–Jn` 展开「结论（左竖线）」「为什么成立」「边界或反例（浅暖米框）」「关键例子」与出处编号，末尾附「专题补充」对比表。
5. **`04` 续聊停点与待决策提案**：独立收束最后具体问题、已明确偏好、未解疑问、陶红细虚线 `[待决策]` 提案与「可从这里接着聊」。
6. **`05` 作者要点与原材料索引**：汇总作者核心要点及三份原文 PDF、`index.md`、`raw/` 定位索引表。

## 3. 原文三件套 PDF 内容组织（纯英文 / 纯中文 / 中英对照）

专门解决原始截图（`.jpg`/`.png`）字小模糊、翻页零碎、纯外文或纯中文单读不便的问题：
- **`<主题短名>·纯英文原文.pdf`**：100% 保留原始英文标题、小节编号（`01`、`02`…）与条目顺序，轻注 `SOURCE S01` / `S02` 分页标记，便于直接读原汁原味英文。
- **`<主题短名>·纯中文原文.pdf`**：按完全相同的编号与条目顺序忠实直译为干净中文，不掺杂 AI 的发挥与长篇解释，便于中文顺畅通读。
- **`<主题短名>·中英原文.pdf`**：把上面两份合并为对照版——每一小节先放英文原段，紧接着用左红棕竖线框配忠实中文译文，方便边读中文边核对英文原词。

## 4. 导出方式与验收标准

- AI 基于 `index.md`（及原文转录）在系统临时目录编写打印专用 HTML，使用本机 Chrome 无头导出：
  ```bash
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --headless=new --disable-gpu --no-pdf-header-footer \
    --print-to-pdf="/主题目录/<主题短名>·认知精华.pdf" "file:///临时打印HTML"
  ```
  同样方式导出 `<主题短名>·纯英文原文.pdf`、`<主题短名>·纯中文原文.pdf` 与 `<主题短名>·中英原文.pdf`。主题目录内只保留 `index.md`、HTML、上述 PDF 文件与未改动的 `raw/`。
- 导出后必须逐页检查所有 PDF：确认页眉页脚单行不折行、无标题孤立、无表格或树图腰斩、所有文字高对比度清晰可读。
