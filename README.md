# 个人认知沉淀

把读到的一份原文和随后与 AI 的完整讨论，整理成一份以后能快速回想、核对原话、继续追问的主题材料。页面优先还原用户的思考过程，保留真正讲透的理由、边界和例子。

## 项目文件

- [index.md 框架与生成规范](./index.md%20框架与生成规范.md) 定义输入、Agent 分析顺序、固定模板、证据定位和归因规则。
- [HTML 回顾页规范](./规范/HTML%20回顾页规范.md) 定义 `<主题短名>·认知精华.html` 的纯白底单栏操作台结构、极简克制配色、思维导图与就地原文对照交互。
- [PDF 排版规范](./规范/PDF%20排版规范.md) 定义 `<主题短名>·认知精华.pdf` 以及外文材料三件套（`纯英文原文.pdf` / `纯中文原文.pdf` / `中英原文.pdf`）的出版级版式与主题命名规则。
- [AGENTS.md](./AGENTS.md) 与 [cognitive-distillation 技能](./.agents/skills/cognitive-distillation/SKILL.md) 配置工作区自动识别规则与完整执行流程：把文章/材料直接发进对话窗口即可自动触发全套产物生成。
- [一键沉淀提示词](./规范/一键沉淀提示词.md) 提供零占位符的「文章 + 提示词」直接粘贴模板（可搭配任何文章或对话发给 AI，自动识别内容与语种并落盘）。
- [AI 生成提示词](./规范/AI%20生成提示词.md) 提供零准备直出、指定目录沉淀、单独返工与跨对话续聊的标准化 Prompt 手册。
- [Naval 样例原材料](./样例/Naval的杠杆/raw) 包含英文笔记的两张原图及用户与 AI 的五轮完整对话。
- 首轮成品放在 `样例/Naval的杠杆/`，包含 `index.md`、`Naval的杠杆·认知精华.html`、`Naval的杠杆·认知精华.pdf`，以及三份原文 PDF（`Naval的杠杆·纯英文原文.pdf`、`Naval的杠杆·纯中文原文.pdf`、`Naval的杠杆·中英原文.pdf`）；另在 [`样例/Naval的杠杆/en/`](./样例/Naval的杠杆/en/) 下提供纯英文四件套版本（`index.md`、`Naval's Leverage - Key Takeaways.html`、`Naval's Leverage - Key Takeaways.pdf`、`Naval's Leverage - Original Text.pdf`）。

## 产物分工

- **index.md** 是主题内容的编辑底稿（唯一事实来源）。换一个 AI 对话，单独上传这份 MD，新 Agent 就能看懂上次的上下文，知道谁说了什么、讨论停在哪，并查到原文转录及完整对话。
- **`<主题短名>·认知精华.html`** 是纯白底、从上往下的单栏交互操作台（带主题名，单独传阅也不重名）。提供吸顶索引与检索、树状思维导图、30 秒速讲卡、可就地展开原文与对话的判断列表，双击即可离线查看。
- **`<主题短名>·认知精华.pdf`** 是出版级长文回顾版 PDF。延续《预设熵增》极简排版，包含思考轨迹、树状脉络图、30 秒速讲提纲、完整判断卡与续聊待决策。
- **原文 PDF 三件套**（针对外文材料；纯中文材料则为 `<主题短名>·原文精排.pdf`）：
  - **`<主题短名>·纯英文原文.pdf`**：只有英文原典，忠实重排。
  - **`<主题短名>·纯中文原文.pdf`**：只有中文直译，不混入扩展点评。
  - **`<主题短名>·中英原文.pdf`**：中英文对照集合版。
- **`en/` 纯英文产物子文件夹**（每个主题目录下均同步产出，100% 纯英文，不含任何中文字符，方便英文阅读或对外分享）：
  - **`en/index.md`**：纯英文版编辑底稿（含英文分析、思维导图节点、原文及已译为英文的完整对话记录）。
  - **`en/<Topic> - Key Takeaways.html`**：纯英文版单栏交互操作台（UI、思维导图、判断卡与原文/对话均全英呈现，原图路径指向 `../raw/...`）。
  - **`en/<Topic> - Key Takeaways.pdf`**：纯英文版出版级长文回顾 PDF。
  - **`en/<Topic> - Original Text.pdf`**：纯英文版原文精排 PDF（页眉页脚与版面标注均全英文）。

## 页面与版式方向

1. **顶部操作与回想。** 吸顶关键词过滤与快捷索引条、核心问题与一句话理解、思考路径、交互式树状思维导图。
2. **速讲与讲透。** 30 秒口述观点卡 + 默认速览的判断列表（可一键切换全展，也可就地展开论证与对应原文/对话）。
3. **续聊与待决策。** 独立呈现最后问到哪里、已明确偏好、尚未解开的疑问与待决策提案。
4. **底部原材料库。** 默认折叠，保留完整原图与转录、以及完整逐轮对话。

视觉统一采用纯白底（`#FFFFFF`）、深炭黑正文（`#141413`）、唯一陶红强调色（`#8B3A1E` / `#B44E2D`），去掉彩色小胶囊，归因仅用极简文字微标。

## 首轮以 Naval 为样例

追踪用户从辨认「杠杆」的含义，到追问「无需许可」和三种杠杆怎么组合，再到问如何开始做自媒体。「先发 10 条」是 AI 最后一轮给出的待决策提案。

先交出一套可检索、可速讲、可核对、可打印、外发不重名的本地样例。原始材料保持原样。本轮范围是规范体系、`index.md`、`Naval的杠杆·认知精华.html`、`Naval的杠杆·认知精华.pdf` 与三份原文 PDF（纯英文 / 纯中文 / 中英对照）。
